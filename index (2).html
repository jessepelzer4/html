Command Prompts

  • Pwd= print working directory = laat zien in welke map je aan het werken bent
  • ls= list
  • cd= change directory = naar een map gaan.
  • man= manual = handleiding
  • tree= mappen structuur
  • touch= maak lege file
  • mkdir= maak nieuw bestand/map
  • rm= remove bestand/map
  • cp= copy
  • mv= verplaatsen
  • nano= command line tekst editor.
  • cat= concatenate= laat de inhoud zien
  • less= laat inhoud zien van 1 pagina per keer
  • head= laat inhoud zien van de bovenkant van een file
  • tail= laat inhoud zien van de onderkant van een file.
